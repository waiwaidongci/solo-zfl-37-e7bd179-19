# 墨锭试磨室

运行：

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`。

## 数据恢复台

主页右上角进入「数据恢复台」（`/recovery`），为全部墨锭、试磨记录、日志和统计提供恢复点：

- **全量 / 增量恢复点**：首个恢复点为全量；之后默认为增量，只记录相对上一点的改/增/删。增量通过 `prevDigest` 链接摘要与父点形成哈希链，沿链可还原全部数据。
- **校验**：每个点都带内容摘要（SHA-256，规范化 JSON）和点摘要。任一点摘要不符、父点缺失或链接摘要不符（断链），该点及其下游都标记为不可用，**预览和恢复一律拒绝**。
- **预览**：恢复前显示将「新增 / 修改 / 丢失」的墨锭数量及明细，并给出目标版本与当前版本的墨锭、日志、试磨总数。
- **恢复**：确认后执行。恢复期间所有业务写入返回 `409 restore_in_progress`，新写入不会混入被回滚版本；恢复采用「备份 → 替换 → 记录完成」的崩溃安全流程，失败或中断（含进程重启）都会自动回到恢复前状态。客户端生成请求 ID，重复/并发的同一请求只执行一次（幂等）。
- **保留策略**：按数量保留，最旧优先清理。被**钉住**的恢复点不会被清理；链上仍被增量依赖的点不会被破坏（自动清理只删链尾或整体淘汰最旧的全量子树）。损坏点不参与自动清理。
- 页面为响应式布局，桌面与手机均可操作。

恢复点与日志存于 `data/recovery/`（`points/`、`journals/`、`pins.json`、`config.json`）。
